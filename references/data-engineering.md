## 🧰 Core tools & frameworks

- [apache/airflow](https://github.com/apache/airflow) — programmatic workflow orchestration.
- [dbt-labs/dbt-core](https://github.com/dbt-labs/dbt-core) — SQL-based analytics engineering / transformation.
- [apache/kafka](https://github.com/apache/kafka) — distributed event streaming platform.
- [apache/spark](https://github.com/apache/spark) — unified analytics engine for large-scale data processing.
- [PrefectHQ/prefect](https://github.com/PrefectHQ/prefect) — modern Python-native workflow orchestration.
- [great-expectations/great_expectations](https://github.com/great-expectations/great_expectations) — data validation and quality testing.
- [delta-io/delta](https://github.com/delta-io/delta) — ACID transactions and lakehouse storage.
- [apache/iceberg](https://github.com/apache/iceberg) — open table format for huge analytic datasets.

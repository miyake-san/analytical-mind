# Data Analytics — Awesome References

## Roadmaps & curricula

- [datacamp – Data Analyst Roadmap (roadmap.sh)](https://roadmap.sh/data-analyst) — interactive, step-by-step skill roadmap.
- [microsoft/Data-Science-For-Beginners](https://github.com/microsoft/Data-Science-For-Beginners) — 10-week, 20-lesson curriculum with a heavy analytics/visualisation focus.
- [ossu/data-science](https://github.com/ossu/data-science) — free, self-taught "open source society university" path that starts from analytics foundations.

## Awesome lists & curated collections

- [PavelGrigoryevDS/awesome-data-analysis](https://github.com/PavelGrigoryevDS/awesome-data-analysis) — 500+ resources spanning analysis, SQL, statistics, visualisation, cheat sheets, and interview prep.
- [kellyjadams/data-analytics-resources](https://github.com/kellyjadams/data-analytics-resources) — practical list focused on the analyst toolkit: SQL, Excel, Tableau, Power BI, Python, R.

## Hands-on practice & references

- [jakevdp/PythonDataScienceHandbook](https://github.com/jakevdp/PythonDataScienceHandbook) — the full handbook as runnable notebooks (NumPy, Pandas, Matplotlib).
- [donnemartin/data-science-ipython-notebooks](https://github.com/donnemartin/data-science-ipython-notebooks) — example-driven notebooks for pandas, visualisation, and statistics.
- [virgili0/Virgilio](https://github.com/virgili0/Virgilio) — a "mentor" repository with structured, beginner-friendly study paths.

## Visualisation & BI

- [matplotlib/matplotlib](https://github.com/matplotlib/matplotlib) — the foundational Python plotting library.
- [plotly/plotly.py](https://github.com/plotly/plotly.py) — interactive, web-ready charts and dashboards.
- [streamlit/streamlit](https://github.com/streamlit/streamlit) — turn analytics scripts into shareable data apps.
- [apache/superset](https://github.com/apache/superset) — open-source BI / dashboarding platform.

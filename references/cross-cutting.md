# ♾️ Cross-cutting — Awesome References

> Foundations and resources that are useful across **every** track: datasets,
> cheat sheets, Python, and the software-engineering practices that keep data and
> AI work maintainable.

[⬅ Back to references index](README.md)

---

## 📦 Datasets

- [awesomedata/awesome-public-datasets](https://github.com/awesomedata/awesome-public-datasets) — high-quality, real-world public datasets across many domains.
- [Kaggle Datasets](https://www.kaggle.com/datasets) — searchable hub of community and competition datasets.
- [Hugging Face Datasets](https://huggingface.co/datasets) — datasets for ML and LLM workloads, loadable in one line of code.
- [Google Dataset Search](https://datasetsearch.research.google.com/) — search engine for datasets across the web.

## 🐍 Python & ecosystem

- [vinta/awesome-python](https://github.com/vinta/awesome-python) — the canonical curated list of Python libraries and tools.
- [Python Roadmap (roadmap.sh)](https://roadmap.sh/python) — interactive Python skill roadmap.

## 🗒️ Cheat sheets

- [kailashahirwar/cheatsheets-ai](https://github.com/kailashahirwar/cheatsheets-ai) — cheat sheets for deep learning and ML libraries.
- [Avik-Jain/100-Days-Of-ML-Code](https://github.com/Avik-Jain/100-Days-Of-ML-Code) — a popular 100-day learning plan with daily, bite-sized lessons.

## 🧱 Software engineering foundations

- [vinta/awesome-python](https://github.com/vinta/awesome-python#testing) — testing and code-quality tooling (section).
- [mehdihadeli/awesome-software-architecture](https://github.com/mehdihadeli/awesome-software-architecture) — curated software architecture patterns and practices.
- [drivendataorg/cookiecutter-data-science](https://github.com/drivendataorg/cookiecutter-data-science) — a logical, standardised project structure for data work (inspiration for the [project template](../projects/templates/project-template/README.md)).

## 🔁 Keeping current

- [roadmap.sh](https://roadmap.sh/) — community-maintained, interactive roadmaps for many of the roles above.
- [ml-tooling/best-of-ml-python](https://github.com/ml-tooling/best-of-ml-python) — ranked, auto-updated list of the best Python ML libraries.

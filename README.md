# analytical-mind

A curated hub to **find awesome repositories and learning materials** across the
modern data and AI career tracks — and a lightweight **scaffolding to build
study projects in parallel** with your learning.

> Learning data and AI is easier when you (1) know *where the best references
> are* and (2) *apply what you learn immediately* on small projects. This repo
> gives you both.

## 1. References — where to find awesome materials

A catalogue of community-trusted repositories, roadmaps, courses, and tools,
organised by track:

| Track | Page |
|-------|------|
| Data Analytics | [references/data-analytics.md](references/data-analytics.md) |
| Data Engineering | [references/data-engineering.md](references/data-engineering.md) |
| Data Science | [references/data-science.md](references/data-science.md) |
| Machine Learning Engineering | [references/machine-learning-engineering.md](references/machine-learning-engineering.md) |
| AI Engineering | [references/ai-engineering.md](references/ai-engineering.md) |
| Cross-cutting (datasets, Python, cheat sheets) | [references/cross-cutting.md](references/cross-cutting.md) |

Start at the [**references index**](references/README.md).

## 2. Study projects — learn by building in parallel

A structure and template to apply what you study right away through small,
finishable projects.

Start at the [**projects guide**](projects/README.md), then copy the
[project template](projects/templates/project-template) to begin.
